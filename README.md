# 宗谱人物子嗣关系交互图

这是一个静态网页版本的宗谱人物关系交互图，用于浏览族谱人物、父子关系、过继关系、人物详情、统计信息和迁徙分布。

## 发布

当前仓库根目录的 `index.html` 即为可直接部署的网页入口，主页面依赖 `assets/` 下的样式、数据和交互脚本。

后续更新时，在本地重新生成页面后，提交根目录页面和 `assets/` 即可同步线上版本。`outputs/` 是生成过程的完整页面副本，不作为人工编辑入口。

## 访问统计

2026-10-04 起通过 [soxft/busuanzi 作者公共服务](https://busuanzi.9420.ltd/)记录累计访问次数及估算访客数，无需注册账号或自建服务器。纸卷、墨砚两套皮肤共 14 页合并为七个栏目；刷新内容页面增加 PV，人物展开、搜索、锚点切换不额外计数。

统计入口和原 `analytics.html` 已从族谱网站移除。独立查看页部署在另一项目中，本仓库不提供它的地址或链接。查看页仅用 GET 查询，不增加访问量。独立页面禁止搜索引擎索引；不公开入口并非登录保护，知道地址或直接查询公共服务的人仍可看到计数。

接入点只有 `assets/site-tools.js`，统一加载仅负责计数的 `assets/site-analytics.js`。生产范围限定为 `https://wushizupu-commits.github.io/zongpu/`；本地预览及其他域名不计数，自动跳转的中间页面跳过计数。网络失败不会影响族谱功能，也不会自动重试 POST 导致重复计数。

UV 结合 IP、浏览器信息和持久访客标识估算，不是精确人数，也不显示具体 IP。只发送固定栏目 URL，不发送人物 ID、搜索文字、查询参数、锚点或来源网址；不携带跨站 Cookie。服务仍能接收到 IP 和浏览器信息。尊重 DNT/GPC；访客标识存储于 `localStorage` 的 `zongpu-analytics-id`，限制存储时仍能计数但去重效果可能变化。

数据从接入后开始累计；不提供日期趋势、来源归因或停留时间。站点总计按域名合并，同域其他接入项目可能并入总数，各页 UV 不能相加。公共服务没有 SLA 或数据完整保证，不能承诺永久保存，也不能防止人为提交重复访问。

参考：[项目 API 源码](https://github.com/soxft/busuanzi/blob/main/app/controller/api.go)。隐藏静态页面地址无法提供身份认证。

### 今日与内容明细（待启用）

公共计数服务不支持按日查询、最近搜索或自定义事件。仓库预留了 Cloudflare Worker + D1 接口：`assets/analytics-config.json` 的 `endpoint` 默认为空，未部署后台时不发送新增事件，原有累计统计照常工作。

启用后，公共统计模块另行记录页面打开、文章面板打开，以及点击或回车选中的搜索结果。仅发送七个固定栏目文件名和族谱已有的文章/人物 ID；不保存访客输入的任意文字，不将新增事件写入不蒜子，也不因此增加原来的页面浏览量。两种皮肤共用同一套采集模块。

新增后台以服务端北京时间划分“今日”，分别保留每日与全部累计 PV、独立 IP、文章打开次数和搜索结果选择次数。独立 IP 是后台用密钥对 IP 做不可逆标识后去重的数量，不代表精确人数，也不显示或保存原始 IP。最近搜索显示已选中的人物与时间，明细保留 30 天，累计数字保留；文章打开不代表已读完。新增明细从后台实际启用后开始，无法补录此前的记录。

部署地址可公开写入配置，但后台读取密钥必须只保存在服务端和本人浏览器会话中，不得提交到 GitHub。统计查看页仍在独立项目中，宗谱站不提供入口或它的地址。

`node --test tests/*.cjs` 验证静态/逻辑回归，统计测试使用模拟 API，不产生线上计数。
